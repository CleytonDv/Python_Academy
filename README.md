# 🐍 Python Academy — Plataforma Interativa de Aprendizado de Python

Plataforma educacional desenvolvida para tornar o aprendizado de Python mais acessível, dinâmico e interativo, utilizando uma experiência inspirada em aplicativos de aprendizagem e gamificação para incentivar a prática e a evolução contínua dos estudantes.

---

## 🚀 Funcionalidades Principais

- **Trilha de Aprendizado**: Organização dos conteúdos em módulos e lições, permitindo uma evolução progressiva no estudo da programação.
- **Conteúdo Educacional**: Estrutura para aulas, explicações, exemplos de código e materiais de apoio voltados ao aprendizado de Python.
- **Exercícios e Desafios**: Atividades práticas para desenvolver o raciocínio lógico e reforçar os conhecimentos adquiridos.
- **Sistema de Gamificação**: Experiência, níveis e recompensas para incentivar a conclusão das atividades e a continuidade dos estudos.
- **Acompanhamento de Progresso**: Recursos para visualizar a evolução do estudante ao longo da trilha de aprendizado.
- **Interface Interativa**: Navegação visual e componentes dinâmicos para proporcionar uma experiência de estudo mais envolvente.
- **Armazenamento Local**: Utilização do `localStorage` para persistir informações de progresso no navegador, quando implementado nos respectivos recursos.
- **Design Responsivo**: Interface preparada para diferentes tamanhos de tela, incluindo computadores, tablets e smartphones.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação das páginas e dos componentes da plataforma.
- **CSS3**: Estilização, identidade visual, animações e responsividade.
- **JavaScript**: Implementação da lógica de interação e dos recursos dinâmicos.
- **LocalStorage**: Persistência local de dados no navegador.

---

## 💻 Como executar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/CleytonDv/Python_Academy.git
```

2. Acesse a pasta do projeto:

```bash
cd Python_Academy
```

3. Abra o arquivo `index.html` em um navegador ou utilize uma extensão como **Live Server**, no Visual Studio Code, para executar a aplicação em um servidor local.
